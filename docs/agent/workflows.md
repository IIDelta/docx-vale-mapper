# Workflows

## Rule Change
1. Update Vale/validator/config.
2. Add unit or fixture coverage.
3. Update rule catalog and coverage policy.
4. Run full gate.

## Refactor
1. No behavior change.
2. Move one bounded responsibility.
3. Update imports/tests.
4. Run full gate.
5. Update architecture and file catalog.

## Word Execution
1. Build plan.
2. Run read-only preflight.
3. Require zero unverified entries.
4. Execute on copied DOCX only.
5. Write execution artifact.
6. Inspect output and re-audit reports-only.
